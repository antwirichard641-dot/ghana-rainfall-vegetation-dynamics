# Research Documentation

This directory contains supporting documentation for the research project, *Rainfall Variability and Vegetation Dynamics as Indicators of Potential Forage Conditions in Ghana (2000–2024)*.

## Documentation topics

- Research objectives and questions.
- Data sources and processing methods.
- Statistical analysis procedures.
- Interpretation of rainfall and NDVI relationships.
- Limitations and recommendations for further research.

## Research scope

The project investigates annual rainfall variability and satellite-derived vegetation greenness in Ghana between 2000 and 2024. It uses CHIRPS precipitation data and MODIS NDVI observations.

NDVI is treated as an indicator of vegetation greenness, not a direct measurement of forage biomass, nutritional quality, or livestock-accessible forage.

## Reproducibility

Methods, assumptions, and limitations should be documented clearly so that readers can understand the analysis and its findings.
