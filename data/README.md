# Data

This directory contains the cleaned and processed datasets used in the Ghana rainfall and vegetation dynamics research project.

## Data sources

- **Rainfall:** CHIRPS precipitation data covering 2000–2024.
- **Vegetation:** MODIS MOD13Q1 NDVI data covering 2000–2024.

## Data management

Processed datasets are documented to support reproducibility. Original datasets remain attributable to their respective providers.

Large raw datasets and files containing sensitive information should not be committed to this repository.
